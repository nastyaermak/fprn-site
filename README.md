# Сайт факультету природничих наук НаУКМА

Django-сайт для факультету природничих наук (ФПрН) НаУКМА. Лабораторна робота курсу ВПА2026.

## Чому саме ФПрН

Моя подруга навчається на біології на факультеті природничих наук, тому мені було цікаво
зробити сайт саме для її факультету: я знаю від неї, як студенти й абітурієнти зараз шукають
інформацію про кафедри та програми і що їм у цьому незручно.

Але спершу треба було переконатися, що окремого сайту в ФПрН справді немає. Для цього я:

1. переглянула [список факультетів](https://www.ukma.edu.ua/index.php/osvita/fakulteti) на
   сайті НаУКМА і сторінку кожного факультету: чи є на ній посилання на окремий сайт;
2. перевірила адреси виду `<факультет>.ukma.edu.ua` (`fin`, `law`, `fen`, `fprn`, `fsnst`
   тощо): які з них відкриваються;
3. пошукала в Google «факультет природничих наук НаУКМА сайт»: знаходяться лише сторінки
   на ukma.edu.ua.

Результат:

### Що є на сайтах інших факультетів

Щоб зрозуміти, яким має бути сайт факультету, я переглянула два факультети, які свій сайт мають:

- **Факультет інформатики** ([fin.ukma.edu.ua](https://www.fin.ukma.edu.ua/)): велика головна з банером і кнопкою «Інформація про вступ»; меню «Новини», «Факультет» (історія, кафедри, партнери), «Навчання», «Студентське життя», «Контакти»; у футері — телефон, адреса, email і дублювання основних розділів.
- **Факультет правничих наук** ([law.ukma.edu.ua](https://law.ukma.edu.ua/)): окремі розділи для кафедр, працівників, освітніх програм, а також «Навчання за кордоном», «Практика і стажування», «Студентські організації».

Спільне в обох: у кожної кафедри є власна сторінка з викладачами, програми описані окремо, а розділи «Кафедри», «Навчання» і «Контакти» доступні з будь-якої сторінки.

У ФПрН нічого з цього немає: сторінка факультету — це підрозділ загального сайту НаУКМА, де меню веде на розділи університету («Абітурієнту», «Наука», «Факультети»…), а не факультету. Окремої сторінки зі списком спеціальностей і координаторами набору немає, а розділу про навчання за кордоном немає зовсім.

Тому на нашому сайті я взяла з цих сайтів те, що найкорисніше абітурієнту:

- головну з банером, як у ФІ;
- окремі сторінки кафедр з викладачами, як у ФІ та ФПН;
- список спеціальностей з координаторами набору;
- розділ програм обміну, аналог «Навчання за кордоном» у ФПН;
- футер з контактами й посиланнями на всіх сторінках, як у ФІ.

Новини, історію факультету й студентське життя поки не додавала: для них потрібен контент, який факультет має оновлювати сам, а в завданні їх не вимагають.

### Що не так з інформацією про ФПрН зараз

Інформація про ФПрН зараз розкидана по різних місцях: опис факультету й кафедр лежить на загальному сайті НаУКМА, освітні програми — в окремому каталозі ECTS, а склад кафедр подано довгими сторінками, де частина даних застаріла (наприклад, на сторінці кафедри екології в шапці й у списку викладачів вказані різні завідувачі). Абітурієнту складно швидко дізнатися, яка кафедра випускає яку спеціальність і до кого звертатися щодо вступу.

Тому на сайті:

- кожна спеціальність має координатора набору (гаранта програми) з контактом;
- для кожної кафедри видно, для яких спеціальностей вона випускова, і повний список викладачів з посадами та ступенями;
- з будь-якої сторінки можна за один клік перейти до кафедр, спеціальностей і програм обміну.

Контент (опис факультету, кафедри, завідувачі, викладачі, освітні програми, дисципліни) взято зі сторінок факультету на ukma.edu.ua і з каталогу ECTS НаУКМА. Координатори набору — з сайту вступу [vstup.ukma.edu.ua](https://vstup.ukma.edu.ua/); для спеціальностей, яких там цього року немає (фізика, лабораторна діагностика), вказано гаранта освітньої програми.

## Сторінки

- `/` — головна: опис факультету і контакти
- `/programs/` — список спеціальностей
- `/programs/<id>/` — сторінка спеціальності з повним описом і дисциплінами
- `/departments/` — список кафедр
- `/departments/<id>/` — сторінка кафедри з викладачами
- `/exchange/` — програми академічного обміну з фільтром за країною

Кафедри, спеціальності, викладачі, текст головної сторінки та програми обміну редагуються в адмінці (`/admin/`).

## Як запустити

1. Створіть та активуйте віртуальне оточення:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

3. Застосуйте міграції (програми обміну з таблиці деканату додаються саме міграціями):

   ```bash
   python manage.py migrate
   ```

4. Завантажте контент факультету:

   ```bash
   python manage.py loaddata fprn
   ```

5. (Необов'язково) створіть адміністратора, щоб редагувати контент:

   ```bash
   python manage.py createsuperuser
   ```

6. Запустіть сервер:

   ```bash
   python manage.py runserver
   ```

Відповіді на питання другої частини — у [ANSWERS.md](ANSWERS.md).
